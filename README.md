# bmhlzr.github.io — GitHub Pages starter

A simple academic homepage inspired by the layout of mischaelkner.github.io, independently written.

## Publish directly on GitHub

1. Create a **public** repository named `bmhlzr.github.io` under the `bmhlzr` account.
2. Upload `index.html` into the repository's root (Add file > Upload files > Commit changes).
3. In the repository, go to Settings > Pages.
4. Under Build and deployment, choose Source: Deploy from a branch, Branch: `main`, Folder: `/ (root)`, then Save.
5. Visit https://bmhlzr.github.io/ once deployment finishes (up to around 10 minutes).

## Customize

- Edit `index.html`: replace `Your Name`, the sample paragraphs, thesis, project, and email entries.
- The example initially pulls your existing public GitHub avatar from `https://github.com/bmhlzr.png`. To use your own photo, upload a file named `portrait.jpg` to the repository and replace the `src` with `portrait.jpg`.
- If you want to link a PDF, upload it to the public repository and use a relative link such as `href="thesis.pdf"`. Anything uploaded here is publicly accessible. Keep private documents in separate **private** GitHub repositories.
- Edit and commit on GitHub whenever you need to update the homepage.
